# Vicmod Achievement Memory 0.0.8

这是 Windows 源码安装发行包，需要 Python 3.12 或以上版本和已安装的 Victoria 3 1.15.x。它包含首页单项记忆、一键记忆当前可记忆成就、个人记忆列表及退出后保存助手。不修改 Steam 成就状态。此 ZIP 不是直接上传 Steam 创意工坊的纯 Mod 包。

## 首次安装

1. 安装 Python 3.12 或更新版本；安装时启用 Python Launcher 或将 Python 加入 PATH。
2. 完整解压到固定位置，例如 `C:\Games\VicmodMemory`。不要直接在 ZIP 中运行，也不要放到游戏原版目录、Steam Workshop 缓存或临时目录。解压路径请使用英文字符。
3. 关闭游戏，双击 `INSTALL.cmd`。安装器尝试识别 Steam 游戏位置；未找到时，粘贴 Victoria 3 安装目录或其中的 `game` 目录。若之前使用过开发版，请先结束旧助手；个人记忆文件可以保留。
4. 安装器从你自己的游戏文件生成 `mod/` 内容，并在真实 Documents 的 Victoria 3/mod 下创建目录链接；已有的其他目录不会被替换。它不会修改启动器数据库或系统执行策略。
5. 重启 Paradox Launcher，在模组库刷新/添加本地模组，通过启动器界面把 **Vicmod Achievement Memory** 加入播放集并启用。首次建议只启用此模组；不要同时启用旧 Capture Probe 或空白 Vic Mod Template。

## 每次使用

1. 游戏未启动时双击 `START.cmd`，等待出现 `MEMORY_READY`。保持助手窗口开启，可以最小化。
2. 从 Steam/Launcher 正常启动游戏。在首页或战役的成就窗口选择“全部”，点击单项“记住此成就”或“一键记忆当前可记忆成就”。只有已解锁项被记忆；筛选页隐藏这些按钮。
3. “我的成就 · 本地记忆”只展示本机记住的条目，新标记在本次游戏内即时显示。尚未实现新成就弹窗自动捕获。
4. 正常退出到桌面，等助手再次输出 `MEMORY_READY` 后再启动下一次游戏或关闭助手窗口。日志可能直到退出时才刷新，因此不要先关闭助手。

新用户首次记忆为空；若本机已经使用过本模组，自己的历史记录会保留。数据保存在真实 Documents 下的 `Paradox Interactive\Victoria 3\vicmod_achievement_memory\records.json`，不在 ZIP 中。`mod/` 是本机生成结果，不要转发给别人；分享本原始 ZIP 即可。

## 更新、卸载与限制

- 更新前退出游戏、等待保存完成并关闭助手窗口。将新版解压覆盖同一安装文件夹，再运行 INSTALL.cmd；不要删除 Documents 下的记忆文件。
- 如果链接已指向别的安装路径，安装器会停止。请通过启动器管理旧模组，再处理旧链接；不要删除已有存档或其他 Mod。
- 卸载前关闭助手并从播放集中停用本模组；保留记录文件即可保留个人记忆。游戏原版和用户存档从不被修改。
- 助手运行时不使用 OCR、不读取游戏进程内存。游戏运行期间只等待进程退出；游戏未运行时每2秒检查进程是否启动。
- 与覆盖原版成就窗口或修改成就分组顺序的 Mod 可能冲突。识别校验不通过的消息会被拒绝，不会猜测为完成。
- 0.0.8开发版本已由作者本机用户验收；本发行包另做了空白用户数据和文件边界测试，仍建议先作为测试发行版。请报告具体游戏版本、点击步骤和错误现象，分享日志时先检查个人信息。
