# 框架验证流程

## 静态与打包检查

```powershell
python scripts/validate_mod.py
python scripts/package_mod.py
git diff --check
git diff --cached --check
```

校验覆盖：元数据字段、稳定 ID、兼容版本、两份 PNG 的结构/CRC/解压长度、封面一致性、ASCII 路径，以及 Mod 包内无功能文件。打包后再核对 ZIP 内容与源文件逐字节一致。

包根应直接包含 `.metadata/metadata.json`，不能多套 `mod/` 或仓库根目录。`dist/` 是生成物，不提交 Git；GitHub Actions 会提供相同类型的构建产物。

## 本机加载与成就验收

1. 重新读取已安装可执行文件与 Launcher 版本，确认目标为 1.15.x。
2. 执行链接脚本，在 Launcher 中新建本项目专用播放集，仅启用本 Mod。
3. 检查名称、封面和兼容版本显示；正常启动，不使用调试启动方式进行成就验收。
4. 新开测试局，不覆盖既有存档。确认能进入游戏，成就规则允许、成就面板可用。
5. 检查当前运行的新增错误；必要时与无 Mod 基线比较。保留本机日志和截图于 `.local/`，只提交简洁结果。
6. 正常退出游戏，记录游戏版本、测试范围和结论。

不要把静态 CI 通过当作游戏运行证据。纯文档变更完成文档检查即可；后续修改游戏加载内容时应重做相应运行测试。

## 成就按钮身份盲测（实验 0.0.5 / 0.0.6）

使用 `python scripts/build_identity_probe.py --game <installed-game-directory>` 更新本地实验目录；失败的旧记忆生成器保持禁用。普通启动 1.15.0（Steam build 26453692），播放集只启用本项目 Capture Probe，不使用调试或成就解锁命令。

进入战役，在成就窗口选“全部”。任选两到三个不同的已解锁成就点击“识别此成就”，最好包括同一组内不同位置及不同组；先由开发者读日志报出点击顺序，再由用户核对，不预先提供成就名称。未解锁条目的按钮应禁用；0.0.6起，“已解锁/可完成/未解锁”等筛选页不显示识别按钮。正常退出以刷新日志，不覆盖已有存档。

开发者执行 `python -X utf8 companion/read_identity_clicks.py --game <installed-game-directory> --logs <user-log-directory>`。读取器只检查最新会话，按原版 `common/achievement_groups.txt` 解析位置，并校验完整分组覆盖、重复 ID、对应表指纹、All/已解锁状态、组数与组内数量、坐标范围。任何失败都报告 rejected，不猜测或写记录。还需核对当前 error.log 中对应接口错误。离线对所有坐标枚举只能证明映射算法，不证明游戏实际返回索引正确。

此实验不支持在“已解锁”或“可完成”筛选页直接识别，因为筛选会改变行索引。尚未恢复记忆面板、自动捕获和跨重启保存，也不使用 OCR；这些不能随按钮识别一起标为通过。

## 本地记忆与显示测试（实验 0.0.7）

1. 在游戏未运行时启动 `python -X utf8 companion/run_memory.py --game "<Victoria 3/game>"`（已有助手运行则无需重复启动）。助手读取已验证的 VICMOD_CLICK_V1 记录，原子合并用户目录的 records.json，并生成同一 Capture Probe 的0.0.7。等待 MEMORY_READY 再普通启动；不要同时运行旧 watch_memory.py。
2. 打开成就 → “我的成就 · 本地记忆”，先检查已导入的“机构建制”“酒品公卖局”“把门开开”是否只各出现一次，名称、说明、彩色图标、分组、滚动及返回按钮是否正常。主菜单也应能查看已保存列表。
3. 返回原版“全部”页，选择另一个已解锁成就点击“记住此成就”；不退出游戏就打开记忆页，检查新条目立即出现，重复点击不重复生成行。其他筛选页不应显示记忆按钮。
4. 正常退出到桌面，保持助手运行并等待约5秒，再启动游戏检查新增项仍保留。助手在游戏进程退出后才读取日志并重建下次启动的快照；不在游戏运行中写GUI，也不假设日志立即刷新。
5. 回报即时显示、图标/文字布局、返回原版、退出重启后的保留结果。游戏内显示及助手跨进程退出行为均需实际检查；离线测试不代替这些结果。

本轮只实现手动记忆链路；新成就自然解锁弹窗的自动捕获仍未接入。用户JSON位于真实 Documents 下 Victoria 3/vicmod_achievement_memory，不能提交Git。构建器限制最多512个唯一成就，每个成就仅在记忆页生成一行；原版每行仍只有一个记忆按钮，禁止在每行内枚举完整目录。

## GitHub 同步约定

用户已授权每次检查及必要测试通过后及时 commit/push。同步前检查 diff 和待提交文件；同步后确认本地 HEAD 与远端 HEAD 相同，并检查该提交的 CI。禁止 force-push，禁止提交本机凭据和原版资源。
